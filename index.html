Rebuild Website Reservasi Pasien

Membangun ulang tampilan dan alur website reservasi pasien yang sudah berjalan, lalu menambahkan layanan baru tanpa mengganggu reservasi yang sedang dipakai pasien setiap hari.

Laravel 12PHP 8.3MySQLjQueryWhatsApp Qontak

Yang saya kerjakan

  • Merombak tampilan dan alur reservasi agar lebih mudah dipahami pasien.
  • Menambahkan modul reservasi vaksin, tes MMPI, dan MCU berbayar.
  • Mengintegrasikan OTP verifikasi akun melalui WhatsApp API (Qontak).
  • Melakukan upgrade aplikasi dari Laravel 9 ke Laravel 12 di server development.

Tantangan teknis

  • Mengembangkan fitur baru di atas kode lama tanpa merusak alur reservasi yang sudah berjalan.
  • reCAPTCHA terblokir Content Security Policy setelah upgrade Laravel 12, lalu diperbaiki dengan menyesuaikan konfigurasi CSP.

Bridging BPJS Kesehatan — WS Antrean FKTP

Menghubungkan sistem reservasi klinik dengan web service antrean BPJS Kesehatan, sehingga data antrean pasien BPJS tersinkron otomatis tanpa input ulang oleh petugas.

LaravelREST APIBPJS WS Antrean FKTPPostman

Yang saya kerjakan

  • Membuat service di Laravel untuk mengirim data antrean ke WS Antrean FKTP BPJS.
  • Menambahkan pengecekan kepesertaan BPJS pasien melalui NIK.
  • Menguji setiap endpoint di environment development BPJS menggunakan Postman.

Tantangan teknis

  • Menyusun header autentikasi BPJS (cons-id, timestamp, signature) untuk setiap request.
  • Mengolah response dari BPJS sebelum datanya bisa dipakai aplikasi.
  • Mengatasi kendala akses ke server development BPJS (timeout) saat pengujian.

Alur sinkronisasi antrean

Login SSO Azure + API Kepegawaian ITB

Menghubungkan login SSO Microsoft Azure dengan API data kepegawaian ITB, sehingga NIP, unit kerja, dan data pegawai terisi otomatis saat pegawai masuk ke sistem.

LaravelSSO Microsoft AzureREST APINICHRIS

Yang saya kerjakan

  • Menghubungkan alur login SSO Azure untuk pengguna non-mahasiswa.
  • Mengambil NIP dan unit kerja dari API NIC berdasarkan akun SSO.
  • Mengambil detail data pegawai dari API HRIS ITB.

Tantangan teknis

  • Menyimpan URL, API key, dan token di file .env, bukan di kode.
  • Mengatur batas waktu (timeout) request agar proses login tidak menggantung saat API lambat.
  • Menyesuaikan konfigurasi SSO yang berbeda antara server development dan production.
